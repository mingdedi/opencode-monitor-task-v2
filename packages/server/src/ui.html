Stored in a cookie on this host (cookies ignore ports) — survives daemon restarts and port changes. Default follows the browser language.

    

  




  
monitor-task dashboard 

  

    

      
What is this

      
Self-hosted dashboard of the monitor-task daemon — same port, same auth as its HTTP API. Independent of opencode's UI: works in any browser tab, alongside TUI / web / desktop.

    

    

      
Authentication

      
Username monitor. Password: opencode service get password (any registered opencode instance, read live — rotation picked up automatically), or the daemon's own password from ~/.local/state/opencode-monitor-task/service.json.

    

    

      
Session jump

      
↗ opens the notification destination in opencode web: {instance}/server/{base64(instance)}/session/{session_id}. The instance must be in the daemon registry (chips in the header). Listen addresses 0.0.0.0/[::] are normalized to loopback for the link.

    

    

      
Notes

      
Polls every second (paused while the tab is hidden). Stop / Delete are two-click actions. Log tail is only available while the task record is in the registry. Creating a task here is equivalent to calling the API directly — the plugin's workspace guard does not apply; directory must be an absolute path. Parameter names (command, max_events, …) stay in English by design.
